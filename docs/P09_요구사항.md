# P09: 비 로그인 서비스 (Standalone) 모드 지원 요구사항

## 1. 개요
- 현재 llm-chat-agent 시스템은 IDP 연동을 통한 로그인이 필수로 구성되어 있으나, 폐쇄망이나 IDP 인프라가 없는 로컬 환경에서도 쉽게 구동하고 테스트할 수 있도록 비 로그인 모드를 도입함.
- 환경 변수 설정을 통해 모든 IDP 연동을 무효화하고 즉시 사용할 수 있는 독립 실행형(Standalone) 모드를 제공하는 것을 목적으로 함.

## 2. 목표
- **환경 변수 유연성 확보**: 환경 변수(`NON_LOGIN_SERVICE`) 설정만으로 시스템이 IDP와 완전히 격리되도록 함.
- **자동 관리자 권한 부여**: 비 로그인 모드 활성화 시, 시스템에 접근하는 모든 사용자를 `nobody` (Admin 권한)로 자동 인식하게 함.
- **토큰 없는 API 사용**: 비 로그인 모드에서는 API 접근 시 API Key(Bearer)나 세션 토큰 검사를 우회하여 개발 및 연동 편의성을 높임.

## 3. 세부 요구사항

### 3.1 환경 변수 및 설정 (Settings)
- `libs/core/settings.py`의 `Settings` 클래스에 `NON_LOGIN_SERVICE: bool = False` 옵션을 추가함.
- 기존 필수(Required) 환경 변수였던 `OIDC_CLIENT_ID` 및 `OIDC_CLIENT_SECRET`를 선택(Optional) 속성으로 변경하여, 해당 값이 없어도 Pydantic 검증 에러 없이 서버가 기동되도록 함.
- `sample.env` 파일에 `NON_LOGIN_SERVICE=True` 옵션 및 설명을 추가하여 운영자가 쉽게 인지할 수 있도록 가이드함.

### 3.2 IDP 연동 차단 및 UI 인증 우회
- **IDP 클라이언트 등록 차단**: `NON_LOGIN_SERVICE`가 `True`일 경우, `libs/core/auth.py` 및 `apps/api/main.py`에서 `authlib`을 이용한 IDP 메타데이터(OIDC Issuer) 조회 및 OAuth 클라이언트 등록을 수행하지 않음 (서버 기동 시 네트워크 통신 원천 차단).
- **인증(UI) 우회**: `apps/api/main.py`의 `_require_user` 함수에서 `NON_LOGIN_SERVICE` 설정 시 세션 체크 없이 즉시 `None`을 반환하여, SPA 메인 화면으로 조건 없이 접근 가능하도록 함.
- **Auth Endpoint 방어**: `/auth/login`, `/auth/callback`, `/auth/logout` API 경로에 접근하더라도 IDP로 리다이렉트되지 않고 메인 페이지(`/`)로 반환되게 방어 코드를 추가함.

### 3.3 API 토큰 인증 우회
- `apps/api/api.py` 및 `libs/core/auth.py`의 `get_current_user` Dependency 로직 최상단에 `NON_LOGIN_SERVICE` 분기를 추가함.
- 분기 통과 시 `UserInfo(sub="nobody", preferred_username="nobody", groups=["Admin"])` 객체를 즉시 반환하여, 모든 API와 도구 랩(Tool Lab) 등의 접근을 "최고 관리자(Admin)" 권한으로 허용함.

## 4. 제약 사항
- 기존 IDP 기반 로그인 기능은 `NON_LOGIN_SERVICE=False` 상태에서 정상적으로 동작해야 하며, 기존 로직이 훼손되어서는 안 됨.
- 보안을 위해 `NON_LOGIN_SERVICE` 기능은 기본값(False)으로 비활성화되어야 함.
